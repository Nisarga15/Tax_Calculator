# Tax Calculator

## Overview

Tax Calculator is a simple web application that calculates the total cost of items in a shopping list by applying the appropriate sales tax. The application helps users quickly determine how much they need to pay before making a purchase.

This project demonstrates basic web development concepts using **HTML, CSS, and JavaScript**, including user input handling, tax calculation logic, and dynamic updates to the webpage.

---

## Features

* Add products to a shopping list
* Automatically calculate applicable taxes
* Display total price including tax
* Simple and user-friendly interface
* Built using basic front-end technologies
